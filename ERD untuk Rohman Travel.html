⚙️ 4. Flow Data ke Database

Saat user booking:

  1. Insert ke bookings

  2. Status = pending

Saat upload pembayaran:

  1. Insert ke payments

  2. Status = menunggu_verifikasi

Saat admin input biaya:

  1. Insert ke operational_costs

  2. Hitung:

keuntungan = total_harga - total_biaya

🚨 5. Hal Penting (WAJIB DI BACKEND)

🔒 Constraint

  • booking_id di payments → UNIQUE (1 booking = 1 pembayaran)

  • booking_id di costs → UNIQUE

🧮 Auto Calculation (JANGAN DI FRONTEND)

Di backend:

total_biaya = bensin + tiket + makan + penginapan + tol + lain_lain
keuntungan = bookings.total_harga - total_biaya

Booking:

  • pending → belum bayar

  • confirmed → sudah diverifikasi

  • selesai → trip selesai

Payment:

  • belum_bayar

  • lunas
